

## 19. 생성 전 · 중 · 후 안내 문구 (v2.4)

기다리는 동안 화면이 늘 같은 말을 하고 있었습니다. **지금 뭘 하고 있는지 알 수 없었고,
빈 화면과 로딩 화면이 겹쳐 보이는 결함도 함께 발견했습니다.**

| 상태 | 이전 | 이후 |
|------|------|------|
| **생성 전** | 「왼쪽 조건을 채우고…」 한 문장 고정 | 안내 + **쓰임새 힌트 5종을 번갈아** 보여 줍니다 — 대상 설정, 우천 대안, 모듈 자동 채움, 접근성 요청, 자료 찾기 |
| **생성 중** | 「숲을 걷는 중입니다…」 고정, 12초에 한 번만 바뀜 | **지나간 시간에 따라 7단계** — 조건 살피기(0초) → 나무 고르기(4초) → 시간표(9초) → 안전·우천(15초) → 마무리 질문(22초) → 지연 안내(30초) → 중단 예고(40초) |
| **생성 후** | 토스트 한 줄뿐 | **걸린 시간 + 다음에 할 일** — 「✅ 12초 만에 수업계획서가 나왔습니다. 현장에서 쓰려면 🔊 현장 진행으로 보내기를…」 (5종 순환) |

### 함께 고친 결함

`.result-empty` 와 `.result-loading` 에 `display:grid` 가 걸려 있어 **`hidden` 속성이 먹지 않았습니다.**
생성을 누르면 빈 화면 위에 로딩이 겹쳐 보였습니다. `[hidden]{display:none !important;}` 한 줄로 해결했습니다.

로딩 영역에 `aria-live="polite"` 를 넣어 **화면낭독기 사용자도 진행 상황을 듣습니다.**

검증: `msgtest.js` — 상태별로 한 화면만 보이는지, 5초 뒤 실제로 문구가 바뀌는지 확인했습니다.
