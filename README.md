# 🌳 무자천서(無字天書) 에듀

> **숲생태 인문학 기반 맞춤형 수업 설계 플랫폼** — 앱 이름 「무자천서 플래너」
> 숲해설가와 생태교육자를 위한 **AI 수업계획서 설계 서비스**
> 조건만 고르면 AI가 수업계획서 초안을 쓰고, 저장·인쇄하고, 현장에서는 음성 안내로 진행합니다.

**배포 URL** : https://여기에-배포후-주소를-붙여넣기.vercel.app
**저장소** : https://github.com/사용자명/mujacheonseo-planner

## 1. 서비스 소개

숲해설 현장에서 가장 자주 벌어지는 일은 "식물 이름 맞히기"로 끝나는 수업입니다.
무자천서 플래너는 그 대신 **오감 체험 · 참여형 활동 · 인문학적 성찰**이 하나로 이어지는
수업계획서를 만들도록 돕습니다. 서비스명 *무자천서(無字天書)* 는
'글자 없는 하늘의 책' — 곧 숲 그 자체가 교재라는 뜻입니다.

### 타겟 사용자

| 사용자 | 상황 | 이 서비스로 해결하는 것 |
|---|---|---|
| 숲해설가 | 매주 다른 대상·계절로 수업을 새로 짜야 함 | 조건 입력 → 10초 만에 초안 |
| 생태교육 강사 | 활동은 있는데 '왜'가 약함 | 철학–생태 매칭으로 사유의 축 확보 |
| 유아·초등 교사 | 숲 체험학습 인솔이 부담 | 안전 지침·준비물·시간표 자동 생성 |
| 숲해설가 지망생 | 수업 설계 연습이 필요함 | 검증된 활동 모듈 6종 열람 |

### 페이지 구성 (8개 섹션 · 상단 메뉴로 이동)

| # | 섹션 | 하는 일 |
|---|---|---|
| 1 | **홈** | 서비스 소개, 활동 모듈 미리보기, 전체 흐름 안내 |
| 2 | **수업 설계** 🤖 | 조건 입력 → **Gemini API 호출** → 수업계획서 생성·수정 |
| 3 | **활동 도서관 · 아카이브** | 활동 모듈 **20종** + 철학 개념 사전 27종 + 노거수 답사지 6곳 + 추천 도서·자료 18종 |
| 4 | **현장 진행** | 단계별 타이머 + **음성 안내**로 수업 운영 |
| 5 | **보관함** | 저장·검색·인쇄·JSON 내보내기/불러오기 |

### 핵심 기능

- 🧭 **수업의 뼈대 4단계** — 관찰(격물) → 관계(연기) → 태도(수용) → 성장(도법). AI가 이 순서로 흐름을 짭니다
- 🔎 **소재 탐색 (AI)** — 목록에 없는 소재를 입력하면 **위키백과 + 구글 검색 그라운딩**으로 자료를 모아
  활동 모듈 초안을 만들고, **참고한 자료 링크**를 함께 보여 줍니다. 저장하면 '내 모듈'이 됩니다
- 🎚️ **난이도 조정 3단계** — 이동 범위·이동 방식·미션 수·안전 수칙이 함께 바뀝니다
- ⚠️ **사실 검증 장치** — 오개념이 생기기 쉬운 모듈에 "해설 전 확인 사항"을 달고, 출처 없는 수치는 AI가 쓰지 못하게 막았습니다
- 🗣️ **해설 모드 3종** — 키즈·청소년 / 일반·성인 / 전문가·해설사. 같은 계획서라도 말의 높이가 달라집니다
- 🎯 **설계 3축** — ① 주제별 관심사 9종(예술·문화·철학·음악·과학·공학·역사·문학·치유)
  ② 프로그램 유형 4종(숲해설·숲활동·숲치유·숲여행) ③ 연령 구분 7종(집중 지속 시간이 설계 제약으로 반영)
- 🤖 **AI 수업계획서 생성** — 대상·시간·계절·생태 주제를 넣으면 학습 목표, 단계별 흐름표,
  단계마다 던질 화두, 준비물, 안전 지침, 성찰 질문까지 한 번에 생성
- 💾 **저장** — 브라우저 `localStorage` 에 보관, JSON 백업/복원 지원
- 🖨️ **인쇄 / PDF** — A4 전용 인쇄 스타일(`@media print`)로 현장용 출력물 바로 뽑기
- 🔊 **현장 음성 진행** — Web Speech API 로 단계 안내, 5분·1분·10초 남음 음성 알림
- 🌗 **다크 모드** — 설정이 브라우저에 기억됨
- 📱 **휴대폰 앱으로 설치 (PWA)** — 홈 화면에 추가하면 주소창 없이 전체 화면으로 열리고,
  **하단 탭바**·큰 터치 버튼으로 한 손 조작이 됩니다. 한 번 연 화면과 저장된 계획서는 **오프라인에서도** 열립니다
- 🩺 **상태·진단 화면** — API 키·모델·연결 상태를 신호등으로 보여 주고, 버튼 하나로 실제 호출을 시험합니다
- 🖐️ **계획서 인터랙션** — 소제목을 눌러 접고, 흐름표 단계를 눌러 완료 표시(진행 막대 연동)
- 📱 **반응형** — 모바일 / 태블릿 / 데스크톱

## 2. 기술 스택

| 구분 | 사용 기술 | 이유 |
|---|---|---|
| 프론트엔드 | **순수 HTML5 / CSS3 / JavaScript (ES6+)** | 프레임워크 없이 구조를 직접 이해하기 위해 |
| 레이아웃 | CSS Grid · Flexbox · CSS 변수(디자인 토큰) | 다크 모드와 반응형을 한 벌의 토큰으로 관리 |
| 백엔드 | **Vercel Serverless Functions (Python 3.12)** | 서버 관리 없이 API 키를 안전하게 숨기기 위해 |
| HTTP 클라이언트 | `requests` | 파이썬 표준에 가까운 간결한 호출 |
| AI | **Google Gemini API** (`gemini-2.5-flash`) | 한국어 품질과 무료 사용량 |
| 저장소 | 브라우저 `localStorage` | 로그인 없이 개인 보관함 제공 |
| 음성 | **Web Speech API** (`SpeechSynthesis`) | 설치 없이 브라우저만으로 음성 안내 |
| 배포 | GitHub → **Vercel** | 푸시하면 자동 재배포 |

## 4. 환경 변수 설정 방법

이 서비스는 **API 키를 코드에 절대 적지 않습니다.** 서버(Vercel)의 환경 변수로만 읽습니다.

| 변수명 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | ✅ | [Google AI Studio](https://aistudio.google.com/app/apikey) 에서 발급한 키 |
| `GEMINI_MODEL` | ❌ | 기본값 `gemini-2.5-flash`. 다른 모델을 쓰고 싶을 때만 |

### 로컬에서

```bash
cp .env.example .env      # 그리고 .env 안에 실제 키를 적습니다
```

`.env` 는 `.gitignore` 에 등록되어 있어 GitHub 에 올라가지 않습니다.

### Vercel 에서

1. Vercel 프로젝트 → **Settings** → **Environment Variables**
2. Name `GEMINI_API_KEY`, Value 에 발급받은 키 입력
3. Environment 는 **Production / Preview / Development** 모두 체크
4. **Save** 후 **Deployments → 최신 배포 → Redeploy** (저장만으로는 반영되지 않습니다)

> ⚠️ 키가 실수로 커밋되었다면: 즉시 Google AI Studio 에서 **해당 키를 삭제(Revoke)** 하고
> 새 키를 발급받으세요. 커밋 이력에 남은 키는 저장소를 지워도 복구될 수 있으므로,
> **키 폐기가 첫 번째 조치**입니다.

## 5. 실행 방법

### 로컬 개발 (AI 기능까지 확인)

```bash
npm i -g vercel        # 최초 1회
vercel dev             # http://localhost:3000
```

`vercel dev` 는 `api/*.py` 를 실제 서버리스 함수처럼 실행해 줍니다.

```bash
python -m http.server 5500
```

브라우저에서 `http://localhost:5500` — 단, 이 방식은 `api/` 가 돌지 않아
AI 생성 버튼은 "연결에 실패했습니다" 안내를 보여줍니다. (의도된 실패 처리)

## 6. 배포 방법

```bash
git add .
git commit -m "feat: 무자천서 플래너"
git push origin main
```

1. [vercel.com](https://vercel.com) → **Add New → Project**
2. GitHub 저장소 선택 → **Import**
3. Framework Preset: **Other** (빌드 설정 없음)
4. **Environment Variables** 에 `GEMINI_API_KEY` 추가
5. **Deploy**
6. 배포 후 `https://<주소>/api/health` 를 열어 `"geminiKeyConfigured": true` 확인

이후에는 `git push` 만 하면 자동으로 다시 배포됩니다.

## 7. AI 기능 명세

| 항목 | 내용 |
|---|---|
| 엔드포인트 | `POST /api/generate` (수업계획서) · `POST /api/discover` (소재 탐색) |
| 자료 수집 | 위키백과 API(키 불필요) + Gemini 구글 검색 그라운딩 → 응답에 출처 목록 포함 |
| 입력 | 제목, **관심사(복수)**, **프로그램 유형**, **연령 구분**, 인원, 시간, 계절, 장소, 철학 배경, 활동 유형, 추가 요청, 숲의 소재 모듈 |
| 출력 | 개요 · 핵심 화두 · 철학 해설 · 학습 목표 · 단계별 흐름표 · 준비물 · 안전 지침 · 성찰 질문 · 확장 활동 |
| 응답 형식 | `{ "ok": true, "model": "...", "plan": { ... } }` |

### 실패 처리 기준

| 상황 | HTTP | 사용자에게 보이는 안내 |
|---|---|---|
| 숲의 소재 미선택 | (프론트) | 경고 팝업 "숲의 소재와 학습 대상을 모두 선택해 주세요!" |
| 제목이 비어 있음 | 400 | 경고 팝업 + "수업 제목을 먼저 적어 주세요" + 빨간 테두리 |
| 관심사 미선택 | (프론트) | 경고 팝업 "주제별 관심사를 하나 이상 선택해 주세요!" |
| 활동 유형 미선택 | (프론트) | "최소 한 가지 활동 유형을 선택해야 합니다" |
| 시간 범위 벗어남 | 400 | "수업 시간은 20분에서 300분 사이여야 합니다" |
| API 키 없음/오류 | 401 | "GEMINI_API_KEY 가 없거나 잘못되었습니다" |
| 사용량 초과 | 429 | "1분 뒤에 다시 시도해 주세요" |
| AI 서버 오류 | 502 | "AI 서버와의 통신이 원활하지 않습니다. 잠시 후 다시 시도해 주세요." |
| 서버측 지연 | 504 | "AI 응답이 40초 안에 오지 않았습니다" |
| 응답 지연(12초~) | — | 로딩바 + "응답이 지연되고 있습니다. 잠시만 기다려 주세요..." |
| 프론트 타임아웃 | — | 45초 후 `AbortController` 로 중단, "응답이 너무 늦습니다" |

## 10. 해설 아카이브 (v1.7)

`public/js/corpus.js` 에 담긴 자료층입니다. 상단 메뉴 **해설 아카이브**에서 5개 탭으로 봅니다.

- **6대 분류 60** — 습성 / 형태 / 자생지 / 쓰임 / 전설 / 귀화
- **화두 50선** — 화두명 · 숲에서 던질 질문 · 관찰 지점
- **노거수 33** — 국가유산포털·위키백과로 교차 확인한 항목만 수록
- **3박 4일 코스 10** — 동선 · 주요 노거수 · 화두 · 해설 포인트
- **정정 기록 18** — 생성형 AI가 만든 원자료 중 근거를 찾지 못해 뺀 항목과 그 사유

원자료(AI가 만든 「노거수 40선」) 40건 중 18건이 오기 또는 근거 미확인이었습니다.
이 앱은 틀린 것을 지워 감추지 않고, **왜 뺐는지를 함께 보여 주는 방식**을 택했습니다.

화두·코스 카드의 버튼을 누르면 수업 설계 폼에 그대로 실립니다.
6대 분류 키워드는 `/api/generate` 요청의 `archive` 필드로 함께 전송됩니다.

## 11. 혼자 듣는 숲수업 (v1.8)

해설가가 없어도 앱이 안내합니다. `public/js/solo.js`

- **대상 5종** — 초등 저학년 / 초등 고학년 / 청소년 / 성인 / 가족.
  고른 대상에 따라 개념어에 쉬운 말이 붙고, 저학년은 해설이 짧아집니다.
- **코스 5종 · 정거장 23곳** — 습성 읽기 / 껍질과 나이테 / 학명 / 화두 / 시민과학
- **정거장 진행** — 찾기 → 해 보기 → 들어보기(음성) → 물음 → 답
  답은 먼저 스스로 답한 뒤 열어 보게 감춰 둡니다.
- **이어서 하기** — 대상·코스·정거장을 이 브라우저에 저장합니다.
- **안전 카드** — 심폐소생술(연령별 압박 깊이·속도), AED, 기도 막힘, RICE, 화상,
  아나필락시스, 경련, 척추 손상, 뇌졸중 FAST. 교육 자료의 수치를 그대로 옮겼습니다.
- **해설가로 넘어가기** — 마무리 화면에서 [이 코스로 수업계획서 만들기]를 누르면
  코스가 「수업 설계」 폼에 실립니다.

특별한 답사지가 필요 없습니다. 동네 공원·학교·아파트 단지에서 되도록 설계했습니다.

## 12. 신화가 남긴 이름 (v1.9)

학명 속에 남은 그리스 신화입니다. 「해설 아카이브 → 신화가 남긴 이름」 탭.

세 갈래로 갈라 두었습니다. 섞으면 틀린 말이 되기 때문입니다.

1. **속명이 신화에서 온 식물** — 붓꽃 *Iris*, 작약 *Paeonia*, 톱풀 *Achillea*,
   어수리 *Heracleum*, 수련 *Nymphaea*, 복수초 *Adonis*, 수수꽃다리 *Syringa*,
   쑥 *Artemisia*, 팥꽃나무·백서향 *Daphne*, 바람꽃 *Anemone* 등
2. **신화에 나오지만 학명은 무관한 나무** — 참나무·피나무(필레몬과 바우키스),
   월계수, 은백양, 사이프러스
3. **숲에서 만나는 동물과 소리** — 호반새 *Halcyon*, 거미 *Arachnida*, 메아리, 큰곰자리

총 22항목, 그중 **14항목은 우리 숲에서 실제로 만날 수 있습니다.**
항목마다 `자생 / 식재 / 남부·온실 / 보기 어려움 / 밤하늘` 배지를 답니다.

**넣지 않은 이야기**도 사유와 함께 보여 줍니다 — 아칸서스와 님프 아칸타(고전 전거 없는 현대 창작),
"아네모네 = 아도니스의 피"(어원 오류) 등 5건.

가장 좋은 소재는 어긋난 자리입니다. 다프네가 변한 나무는 월계수인데
*Daphne* 속은 서향·팥꽃나무입니다. 이 어긋남을 그대로 이야기하면
학명이 왜 필요하고 왜 완벽하지 않은지가 한 번에 설명됩니다.

「혼자 듣는 숲수업」에도 같은 이름의 코스(정거장 6곳)를 넣었습니다.

## 13. 비밀값 보호 (v1.10)

### 무슨 일이 있었나
`GEMINI_MODEL` 환경 변수에 모델 이름 대신 **API 키가 잘못 들어가**,
공개 진단 화면 `/api/health` 의 `modelCandidates` 에 그 값이 그대로 노출되었습니다.
발견 즉시 키를 폐기·재발급하고, 아래 두 겹의 장치를 넣었습니다.

### ① 입력 검사 — `safe_model_name()`
환경 변수의 값이 **모델 이름의 형태**일 때만 받아들입니다.

- `gemini` / `gemma` / `models/` 로 시작
- 영소문자·숫자·점·하이픈, 3~60자
- `AIza` `AQ.` `ya29.` `sk-` `Bearer` 로 시작하면 무조건 거부

형태가 어긋나면 그 값은 **후보에서 빠지고 응답에도 담기지 않으며**,
`modelEnvValid: false` 로만 알립니다.

### ② 출력 검사 — `redact()`
밖으로 나가는 모든 문장에서 비밀값처럼 보이는 것을 지웁니다.
구글의 오류 메시지가 요청 URL을 통째로 되돌려 주는 경우가 있기 때문입니다.

| 지우는 것 | 결과 |
|---|---|
| `?key=…` / `&key=…` | `?key=[숨김]` |
| `AIza…` `AQ.…` `ya29.…` `sk-…` | `[숨김]` |
| `Bearer …` | `Bearer [숨김]` |
| 환경 변수에 실제로 든 값과 일치하는 문자열 | `[숨김]` |

`api_error_text()` 가 이 함수를 거치므로, `/api/generate` · `/api/discover` ·
`/api/health?probe=1` 의 모든 오류 문구가 함께 보호됩니다.

### 키가 새어 나간 것 같을 때
1. https://aistudio.google.com/apikey 에서 해당 키 **삭제** 후 새로 발급
2. Vercel → Settings → Environment Variables → `GEMINI_API_KEY` 교체
   (`GEMINI_MODEL` 에는 **모델 이름만**. 비워 두어도 됩니다)
3. Deployments → **Redeploy**
4. `/api/health` 를 열어 `geminiKeyConfigured: true` 와
   `modelEnvValid` 가 `null` 또는 `true` 인지 확인

## 14. 신화 생태 융합수업 100차시 (v2.0)

「해설 아카이브 → 신화 생태 100차시」 탭. 데이터는 `public/data/lessons.json`.

그리스 로마 신화 한 편에 우리 자연 한 가지를 붙인 **초등 3~6학년 100차시 교육과정**입니다.
회당 80분, 사계절 운영(봄·여름·가을·겨울 각 25차시).

**차시마다 18개 항목** — 신화 소재 / 인문학적 의미 / 미술 표현 / 생태 탐사 / 준비물 /
핵심 발문 / 평가 포인트 / 우리 자연(국명·학명) / 조선왕조실록 검색어와 연계 주제 /
**탐방 낭독 대본** / 현장 해설 팁

낭독 대본은 **음성으로 읽어 줍니다.** 계획서를 들지 않고도 현장을 진행할 수 있습니다.

**검증**
- 학명 **12건 정정** — 꿀벌 *Apis cerana* → ***A. mellifera***, 문어 *O. vulgaris* → ***O. sinensis***,
  `Fungi`(계 이름) → 표고 *Lentinula edodes* 등
- **28차시에 안전 주의** — 복수초·수선화·상사화의 독성, 야생 버섯 금지,
  구렁이·삵(멸종위기) 접촉 금지, 관박쥐(광견병), 참게·가재(폐흡충), 벌 쏘임 등
- 이 안전 내용은 「혼자 듣는 수업」의 **안전 카드에도 반영**했습니다

**사용**: 계절·영역 필터 → 카드 펼치기 → 🔊 대본 듣기 → [이 차시로 수업 설계]
