

## 20. 선택함 — 여러 자료를 담아 한 수업으로 (v2.5)

해설 아카이브의 버튼은 지금까지 **「이 화두로 수업 설계」 하나뿐**이었습니다.
누르면 곧바로 폼으로 넘어갔고, **두 가지를 함께 쓰고 싶으면 방법이 없었습니다.**
노거수 한 그루와 그에 얽힌 신화, 거기에 맞는 화두 — 실제 수업은 늘 그렇게 만들어지는데도요.

### 담고 → 모으고 → 만든다

| 단계 | 하는 일 |
|------|---------|
| **담기** | 모든 카드에 `＋ 담기` 가 붙었습니다. 갈래를 옮겨 다니며 여러 개를 담습니다 |
| **선택함** | 화면 아래 막대에 담긴 것이 쌓입니다. 칩의 `×` 로 하나씩 빼거나 통째로 비웁니다 |
| **수업으로** | `선택한 자료로 수업계획서 만들기` → 제목·소재·요청 사항이 자동으로 채워지고 설계 폼으로 넘어갑니다 |

담을 수 있는 갈래는 **11종 · 350개 항목**입니다.

| 갈래 | 개수 | 갈래 | 개수 |
|------|-----:|------|-----:|
| 6대 분류 | 60 | 신화 | 22 |
| 화두 | 50 | 정정 기록 | 18 |
| 학명 | 44 | 코스 | 10 |
| 노거수 | 33 | 동궐도 | 10 |
| 100차시 | 100 | 현장 노트 | 7 |
| 시나리오 | 6 | | |

### AI 에게 어떻게 넘어가는가

담은 자료는 `payload.picks` 로 실려 프롬프트에 이렇게 들어갑니다.

```
해설가가 앱의 '해설 아카이브'에서 직접 골라 담은 자료 4개입니다.
이 자료들은 이번 수업의 뼈대입니다. 하나도 빠뜨리지 말고, 서로 이어지는 하나의 흐름으로 엮으세요.
억지로 나열하지 말고, 왜 이것들이 한 수업에 함께 놓이는지 그 연결을 만들어 주세요.
  · [노거수] 양평 용문사 은행나무 — 은행나무 · 천연기념물 · …
  · [신화] 작약 · 백작약 — Paeonia · 신들의 의사 파이온 — …
```

**「연결을 만들어 주세요」가 핵심입니다.** 자료를 나란히 붙이는 것은 사람도 합니다.
왜 이 넷이 한 시간 안에 함께 놓이는지 — 그것이 AI 에게 맡길 일입니다.

### 설계 판단

| 결정 | 이유 |
|------|------|
| 최대 **12개** | 더 담으면 프롬프트가 산만해져 어느 자료도 깊이 다루지 못합니다 |
| `localStorage` 에 저장 | 오늘 담아 두고 내일 이어서 만들 수 있어야 합니다 |
| 백업 대상에서 **제외** | 선택함은 작업 중 상태이지 결과물이 아닙니다. 보관함(계획서)과 성격이 다릅니다 |
| 기존 「바로 수업 설계」 **유지** | 하나만 쓸 때 두 번 누르게 만들 이유가 없습니다 |
| 설계 폼에도 **선택 자료 칸** | 무엇을 근거로 만드는지 만들기 직전에 다시 보여야 합니다 |

검증: `picktest.js` — 11갈래 담기 버튼 존재, 갈래를 넘나든 다중 선택, 다시 그려도 유지되는 ✓ 표시,
칩 삭제, 폼 자동 채움, `payload.picks` 전달, 12개 한도, 망가진 저장값 방어까지 확인했습니다.
